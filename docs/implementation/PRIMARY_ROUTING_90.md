# Source90 — отступы у камер и независимый допуск сохранённого экспорта

Тип изменения: исправление B-10 и связанного пропуска проверки при экспорте. Это не новая
эвристика оптимальности, не кеш готовых маршрутов и не приёмка всей геометрии. Версия основного
алгоритма — `global-tree-90`; runtime61 и VPS этим checkpoint не обновляются.

## Основание и границы исключения

Повторно прочитаны оригиналы `Техническое_приложение_ЛЦТ_новое.docx` (§§2.2, 2.4) и
`Разъяснения по вопросам ЛЦТ.docx` (вопросы3,11). Исключение из отступа к ОКС относится только
к финальному прямому вводу в собственный полигон подключаемого потребителя. Оно действует
и на часть такого ввода перед стеной; остальные ограничения сохраняются.

Ни существующая камера, ни выбранная врезка **не получают общего исключения из отступа
чужого здания**. Поэтому прежнюю гипотезу «сохранить endpoint-льготу только для существующей
врезки» из handoff89 применять нельзя. Упоминание допустимой точки присоединения в §2.4
не разрешает нарушение §2.2/таблицы2. Downloads не изменялись.

## Исправление

- `applicableConstraints` больше не заменяет весь буфер ОКС его footprint только потому,
  что начало или конец проверяемого участка находится внутри буфера. Это действует в поиске,
  сборке коридоров и независимом валидаторе. Явная обработка собственного ввода сохранена.
- `SavedForbiddenClearanceAssessment` проверяет сохранённые рёбра перед выдачей первой feature
  любого выбранного варианта. Проверяются исходная полилиния и фактические координаты секций,
  фактический ДУ, запрещённые препятствия и ввод собственного ОКС. `valid=true`, rank и полная
  сохранённая смета не заменяют эту проверку. Старый неверный результат остаётся читаемым,
  но экспорт требует перерасчёта.
- Пространственная часть `OfficialRouteValidator` используется повторно через отдельную сессию:
  нет второй формулы отступа или второй трактовки собственного ввода. Сессия подготовки имеет
  прежние ограниченные бюджеты и не хранит маршруты. Геометрия материализуется для одного ребра;
  все полилинии сети одновременно не копируются. Это не утверждение о полном streaming импорта.
- Обычные и потоковые entrypoints используют общий preflight. Проверка специальных переходов
  road/tram и их сохранённой разметки остаётся в `SavedSpecialClearanceAssessment`; её допуски
  округления не заменяются более грубой новой проверкой. Связность/камеры/повороты проверяются
  существующим `SavedChamberAssessment` до нового допуска.
- Коллинеарные точки технического разбиения не укорачивают финальный прямой ввод. Убираются
  только строго сонаправленные коллинеарные точки, с точным decimal cross-product; смещение
  на миллиметр сохраняется и проверяется. Исходный JSON не изменяется.
