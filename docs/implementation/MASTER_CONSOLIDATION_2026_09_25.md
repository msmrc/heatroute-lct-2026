## Совместная работа

`master` — единственная рабочая ветка. Перед правками: fetch, status, проверка владельца
файлов в параллельных задачах. Git switch/merge/commit/push выполняет одна задача за раз.
Не применять force push/reset, не прятать незавершённые чужие правки в общий `git add .`.
Перед каждым push повторить fetch и проверить ancestry; удалённые новые коммиты сначала
сохранить нормальным merge. Production обновлять отдельно только после соответствующих gates.
