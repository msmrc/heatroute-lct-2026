# Дополнительные сценарии, не официальный эталон

`roads-kindergarten.geojson` — пользовательский файл от 25.09.2026, копия без изменений:
SHA-256 `acac7a6885f53faa360becde85bcfea6571eb01c60bcf106da7b2c378918125b`.
307424 байта; 239 объектов: исходные 144 Feature сохранены, добавлены 94 ограничения дорог
с OSM-атрибутами и одна экспериментальная территория детсада (`social_area`). Все 17 точек
подключения и их расходы совпадают с `../official/lct-2026.geojson`.

Добавленные объекты помечены `experimental: true`; это не кадастровая/исполнительная съёмка.
В исходном файле не указаны дата выгрузки OSM, способ построения габаритов и точность дорог.
Их нельзя объявлять официальными данными или выдавать предположение о ширине 6 м за измерение.
Для публикации производных данных учитывать [атрибуцию OpenStreetMap](https://www.openstreetmap.org/copyright).

Сценарий загружается отдельно обычным импортом; не меняет встроенный официальный demo.
Его назначение — проверять пересечения дорог, запрет чужих социальных территорий и время работы.
Нахождение точки внутри social_area само по себе не даёт разрешения на пересечение территории
по письменному ТЗ: это отдельный открытый вопрос, отмеченный в
[плане доводки](../../docs/implementation/EXPERT_ROUTING_2026_09_25.md).

Проверка происхождения: `node --test scripts/scenario-datasets.test.mjs`.
Она проверяет целостность данных, не заменяет Java-валидацию, import → plan → export или
оценку допустимости расчётной трассы.
