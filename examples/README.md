# Демонстрационные примеры

Все объекты, разрешения, мощности, отступы и цены вымышлены. Это не данные Москвы и не инженерная методика. Привязка к географическим координатам нужна только для проверки карты и преобразований.

`manifest.demo.json` содержит hashes и назначение набора. `canonical_features.demo.geojson` — 19 искусственных объектов: здания, дорога, коммуникация с неизвестной глубиной, условная сеть, кандидаты, два перехода и точка входа. Это нормализованный fixture, который будущий seed/import должен провалидировать тем же canonical validator, а не обходить проверки.

`scenario.demo.json` задаёт воспроизводимый ввод. Готовой линии трассы здесь намеренно нет: её должен вычислить backend. `run_request.demo.json` — пример HTTP envelope для запуска уже сохранённой revision, не отдельный request DTO целиком.

`rule_profile.demo.json` и `cost_catalog.demo.json` показывают версионируемые настройки. Ни 3 метра отступа, ни условные цены не являются рекомендацией для реальных объектов. Цена за pipe_m относится к отдельной трубе; земляные работы и переходы оцениваются по отдельным единицам.

`raw_buildings.demo.geojson` и `import_mapping.demo.json` — отдельный минимальный пример внешней схемы с сантиметрами. Это не полная территория для маршрутизации: он проверяет mapping и перевод 1200 cm → 12 m.

`tests/fixtures/algorithm_cases.json` использует локальные метры, **не GeoJSON**. Это компактные постановки для будущих tests solver: прямой путь, обход, полный барьер и щель, где ось проходит, но коридор не помещается.

`tests/fixtures/entropy_research.json` относится только к анализу материалов пользователя. Оно воспроизводит формулу и демонстрирует ошибочную T/совпадение T и U; не используется в маршрутизации и расчёте мощности.

Проверка внутренней согласованности примеров:

```bash
python scripts/validate_spec_examples.py
```

Запускать из корня комплекта либо любым путём: скрипт определяет корень относительно собственного файла. Требуется Python 3.10+; внешние пакеты не нужны. Это проверка примеров, не приложения, которого пока нет в этом комплекте.
