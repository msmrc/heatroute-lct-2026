## Причина геометрического дефекта

В66 после завершения всего portfolio выиграла другая сеть, чем при раннем выборе
engineering/shortest. Она уже не попадала в `regularizeEngineeringDraft`, хотя тот мог
исправить оставшийся угол. Сам `finish(engineering)` не эквивалентен полной доводке черновика.

Диагностический replay **результата66**, не новый fresh67:
2092,274→2090,416м;11новых камер+1существующий корень;24→23поворота;
1неподходящий угол179,426°→0;285145228,70→284949407,70₽;17/17, полная глубина,
strict export PASS. Время локальной доводки2,728с. Evidence `source66-cheapest-repair.log`.
Это не кеш готового маршрута и не доказательство результата67: сохранённый вариант
использовался только для диагностики места пропущенного этапа.

Исправление: поздний cheapest с экспертными нарушениями получает одну дополнительную
доводку существующего дерева без перестройки зон и полный `finish(engineering)`.
Исходные роли сохраняются. Дополнительный вариант принимается только при том же охвате,
корректной геометрии/ДУ/включённой глубине, нуле экспертных нарушений, полной экономике,
длине и цене не выше исходных. Затем повторяется существующий отбор ролей и перенос камер.
Objective, угловые допуски, собственный ввод и правила итогового экспорта не менялись.

## Отдельная оптимизация, сохраняющая поведение

`NavigationObstaclePreparation` подготавливает buffer/hull/опоры forbidden-препятствия один раз
между расширениями75/200/600м и pocket-fallback **одного** find/findAfter. Ключ — идентичность
Constraint, не feature ID. Между поисками контекст не переносится; путей он не хранит.
Окна, порядок опор, endpoint-dependent pockets, special portals и валидация неизменны.

Удержание ограничено128препятствиями/32768координатами boundary+hull+support. Переполнение
возвращает прежнее вычисление без удержания. Это не лимит всех байтов JTS и не ограничение
одной временной геометрии; scale gate не заменяется этой оценкой.
