- Удалено неподтверждённое снятие `social_area` в нормальном вводе собственного ОКС.
  Генератор, итоговый validator и exporter используют общее правило: исключение только
  для точного собственного `oks`. RED20 → GREEN180; положительный ввод собственного здания

- После обязательного ремонта камер добавлен один ограниченный проход объединений:
  не более двух уникальных допустимых seeds, шесть финализаций на seed. Исходные варианты
  сохраняются, бюджет качества не накапливается. Focused82 PASS, integrated replay PASS:
  2039,856→2025,854 м, 14→13 узловых камер, 294233458,44→285083697,19 ₽, 17/17.
  Более дешёвый 2024,918 м с `NO_VERTICAL_PASSAGE` отклонён. Наблюдённое время23,033с
  относится только к этому этапу; это ещё не новый полный расчёт.
- Содержательное объединение одинаковых публичных вариантов реализовано. Внутренние роли
  поиска сохраняются, итог содержит до трёх разных решений с официальными rank/score.
  Учитываются реальные исходные врезки, группы потребителей, специальные проходы и обходы
  препятствий; ID технических узлов и небольшие сдвиги не создают новую альтернативу.
  Препятствия между сравниваемыми трассами запрашиваются и в серверном оконном режиме.
  RED18/19 на прежней публикации копий, отдельный windowed RED; интеграция прошла общий fast.
  Старое требование теста «всегда ровно три» заменяется контрактом §6, а не имитацией третьей сети.
- Доказанно запрещённые вводы отделяются до генерации: только строгая принадлежность
  территории с запретом, без вывода о невозможности по неудаче эвристического поиска.
  Все исходные потребители, причины `ENDPOINT_INSIDE_FORBIDDEN_AREA`, typed blockers и
  штрафы остаются в результате и промежуточной экономике. Оконная загрузка сохранена.
  RED2 → focused73 PASS, включая depth, поворот, порядок входов и две законные точки
  рядом с запрещённой. Evidence: `.tooling/expert94/terminal-partition/EVIDENCE.md`.
- Дополнительный контроль all-blocked/shared4+1: все потребители и штрафы сохраняются
  в обоих режимах глубины. Он выявил отдельное падение на допустимом вводе без контура ОКС:
  выбранная точка сетки могла совпасть с терминалом. Два фильтра до построения примыкания
  устраняют сбой, прочие точки сетки остаются доступны. RED2 → focused60 PASS.

## Дорожная граница: требуется решение пользователя

§4 таблица2 задаёт специальный участок дороги/трамвая по3м за границей; §3.1 измеряет
нормативный отступ от габарита пары, а вне special требуется1,5м. Для прямого пересечения
совместимость обычного участка требует `1,5 + W/2 <= 3*sin(angle)`.
ДУ1200/1400 с шириной3,1/3,45м не совместимы с обычным участком сразу после этих3м даже
при90°. При45° ДУ300 проходит, ДУ400 не проходит. Это ограничение буквального текста,
не доказанный дефект программы. Автоматическое удлинение special меняет границы и стоимость;
Google не даёт разрешения интерпретировать3м как минимум. Вопрос отправлен пользователю.
До ответа зависимое инженерное правило не меняется. Focused совместимость20 + existing68 PASS,
полная матрица146 PASS; `.tooling/expert94/road-margin/EVIDENCE.md`.

## Следующие проверки

Свежий roads+kindergarten, производительность, долгие corridor-контроли и release smoke
ещё не приняты; локальные official/экспорт/содержательные альтернативы проверены выше.

нужны доказанная причина no_route и корректная обработка остальных потребителей.
После каждого геометрического прогона пользователю отправляется изображение результата
с версией, состоянием проверки, покрытием, длиной и числом камер; replay подписывается отдельно.

Исторический <1860м/<=13 камер — внутренний raw-draft benchmark source63, а не норматив ТЗ.
Порог не меняется для зелёного suite. Его исходная камера не проходит актуальные нормали;
достижимость компактной законной сети проверяется отдельно. Полная цель, R/G и scale остаются
открытыми. Подробный аудит: `.tooling/expert94/requirements-audit.md`, `compact-audit.md`.

validator требует не заданный актуальным §5 шаг0,5м, а внутренний выбор профиля может
предпочесть более дорогой вариант по горизонтальной проекции. Воспроизведение на неизменных
final1 classes: `.tooling/expert94/depth-audit/probe.log`; оно не меняет текущий расчёт.
