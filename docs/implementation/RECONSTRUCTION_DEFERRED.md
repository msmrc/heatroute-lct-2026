# Отложенная реконструкция существующей сети

## Решение

Реконструкция не придумана текущим алгоритмом. Она предусмотрена полной постановкой задачи:
добавленный расход от новой точки подключения должен распространяться к источнику по существующей
сети, после чего требуемый ДУ сравнивается с текущим ДУ участка. Участки и камеры, которым нужен
больший ДУ, попадают в результат реконструкции и в расчёт стоимости.

Для профиля `baseline_input` реконструкция временно не обязательна. Это не означает её удаления из
продукта: полный расчёт сохранён для `extended_input`.

## Почему базовый файл недостаточен

В текущем базовом GeoJSON отсутствуют данные, без которых результат пришлось бы выдумывать:

- текущий `flow_tph` существующих участков;
- направление к источнику через `upstream_object_id`;
- диаметр части существующих камер.

Поэтому система выдаёт предупреждения, но не создаёт фиктивные объекты реконструкции и не блокирует
2D-маршрут, стоимость новой сети, ранжирование и экспорт базового результата.

## Когда вернуть вопрос в активную разработку

Вернуться к обязательной реконструкции нужно при появлении хотя бы одного из условий:

1. предоставлен новый набор с полным baseline существующей сети;
2. письменно подтверждён способ восстановления направления и исходных расходов;
3. определён контракт реконструкции для наборов с частично отсутствующими полями;
4. появились отдельные проверочные примеры для участка, камеры и общей upstream-ветви.

## Чек-лист повторного включения

- проверить связность `upstream_object_id` до источника и отсутствие циклов;
- проверить исходные расходы и ДУ всех затронутых участков;
- распространить добавленный расход вверх по сети;
- выбирать минимальный допустимый ДУ по таблице;
- включать только реально изменяемые участки и камеры;
- добавить стоимость реконструкции и длину в итоговую оценку;
- проверить частичный результат при неполном baseline;
- прогнать отдельные contract-тесты `extended_input` и экспорт реконструкции.

До выполнения этих условий реконструкция остаётся поддерживаемой, но отложенной возможностью, а не
обязательным элементом каждого результата.
