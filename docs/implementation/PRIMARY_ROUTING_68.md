терялись. Неухудшение длины/цены ремонта не доказывает неухудшение последующего локального поиска.

поздний экономический вариант ремонтируется до75м и вытесняет её перед переносом.

у исходной сети новая корневая камера на существующемДУ1000, у альтернативы две готовые
врезки; они обеспечивают нужный порядок стоимости без подмены расчётчика.

В68 для relocation сохраняются все исходные роли плюс один дополнительный repair-кандидат:
не более4seeds вместо3. Промежуточный отбор удалён, финальный selector и все допуски прежние.
