# Source97 — допуск поворотов в дорожном коридоре

Обычный поворот внутри прямого специального прохода мог попадать в дерево поиска,
после чего независимая финальная проверка отбрасывала весь маршрут. Поиск теперь проверяет
обе стороны поворота через существующие правила специальных проходов. Проверка работает
в расширении пути, присоединении к дереву и после объединения/обрезки metric-MST.
Прямое продолжение, параллельный ход и допустимые углы дороги по ТЗ сохраняются.

Версия алгоритма: `global-tree-97`. Изменения глубины и ускорение пересечений наследуются
от source96. Новый Google от 27.09.2026 ещё не внедрён: этот checkpoint не является
подтверждением новых минимумов камера→поворот 2–6 м. Источники и приоритеты находятся
в ACTIVE_ROUTING_RULES.md. R/G не закрыты; в production остаётся source95.

## Проверки

- Frozen `.tooling/expert97/final1`: 2052 случая, 2049 PASS, 0 failures/errors,
  3 opt-in scale skip, 180 классов. Исключены три длинных dataset/control класса.
- Focused turn admission: 136 PASS. Независимая проверка: 6360 синтетических assertions,
  18 directed cases (246 assertions), 48 граничных случаев (144 assertions).
- 5000 малых взвешенных графов не дали недопустимого дерева. Это дополнительная проверка,
  не доказательство воспроизведения прежнего дефекта финального объединения MST.
- Короткая генерация root126 на настоящих PostGIS WKB и source-order/windowed контексте:
  раньше 0 сетей / 24,345 с, финальный patch 32 сети / 26,825 с, 8 уникальных.
  Кратчайший черновик 2176,043 м, 16 подключений + запрещённый ввод №11.
  Полные finish/repair/depth/export этим запуском не проверены.
- Карта фактического черновика просмотрена и отправлена пользователю.
- Новый полный official/roads, свежие web gates и VPS smoke для97 не выполнялись.
  Результаты96 не заменяют эти проверки. Локальные pwsh/Docker отсутствуют;
  обязательный Compose smoke выполняется на VPS при следующем готовом релизе.
