# Source92 — реальные примыкания существующей сети к камерам

Тип изменения: correctness, версия `global-tree-92`. Источник — явное уточнение в
[актуальном документе Евгения](https://docs.google.com/document/d/1i4ZUJLpCAagwWk0K15uQAgT8bhftGQENQsd4OyTCO60/edit):
проходящая через камеру существующая линия занимает два примыкания; конец — одно.
Общий лимит остаётся четыре линейных участка. Это отдельное исправление после merge
`e5d8d01`, а не behavior-preserving оптимизация source91.

## Ошибка и исправление

Planner и topology analyzer считали Features, а не примыкающие части геометрии. Поэтому
неразбитая проходящая линия оставляла камере лишний слот. Сохранённый заниженный счётчик
также мог попасть в независимый допуск и экспорт.

`ExistingNetworkIncidence` индексирует исходные `heat_network` и считает примыкания в
EPSG:32637 с прежним snap-допуском 1 см. Внутренняя вершина даёт два луча, endpoint — один,
раздельные линии учитываются независимо. Самопересечение и повторное прохождение через
камеру не ограничены двумя примыканиями на Feature; короткие технические и повторные
вершины не создают лишних выходов.

Подсчёт используется при поиске root, topology reuse, независимой финальной проверке и
проверке saved export по исходному импорту запуска. Экспорт отклоняет переполнение до
выдачи features. Старый JSON не переписывается. Обычный planner-путь не получает отдельный
набор правил, и ширины, расходы, ДУ, отступы, ранжирование и цены не изменены.

## Ограничения и продолжение

При отсутствии доступной опорной геометрии existing root сохраняет прежнюю совместимость
с историческим счётчиком. Это исправление не добавляет строгую проверку наличия опоры.
Входной контракт допускает для heat_network только LineString и запрещает повторные ID.

Строгие перпендикулярные примыкания камеры, ближайший поворот в 2 м и дороги 90–100° —
отдельные открытые требования. Для 2 м требуется уточнение «ровно» или «минимум»;
дорога должна проверяться согласованно с ТЗ и локальной геометрией её поворота.
Схема не задаёт фиксированные координаты или эталонную длину.
Fresh полный набор, compact, дороги17/17, Compose, production deploy, R/G и scale этим
checkpoint не закрываются. Доступные native проверки не заменяют release smoke.
