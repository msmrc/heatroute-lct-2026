# Машиночитаемые контракты HeatRoute

В каталоге опубликованы три JSON Schema Draft 2020-12:

- `lct-2026-input.schema.json` — строгий семитиповый вход из технического приложения;
- `lct-2026-provided-dataset.schema.json` — явно названный compatibility-профиль фактически
  переданного организатором файла;
- `lct-2026-output.schema.json` — строгий семитиповый результат HeatRoute.

JSON Schema проверяет форму каждого объекта, типы, допустимые ДУ и диапазоны координат. Инварианты
между объектами — глобальная уникальность ID, ссылки, направление к источнику, дерево, количество
summary и равенство итоговой стоимости сумме компонентов — дополнительно проверяются потоковыми
Java-валидаторами. Схема не заменяет эти проверки.

CI компилирует все три схемы полноценным Draft 2020-12 валидатором, проверяет официальный файл
по compatibility-схеме и проверяет фактический результат экспортера по output-схеме. Поэтому файлы
нельзя менять как необязательную документацию: они являются тестируемой частью контракта.
