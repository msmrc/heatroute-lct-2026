# Source96 — глубина всей сети и проверка сохранённого экспорта

## Исправления

По [действующим требованиям](ACTIVE_ROUTING_RULES.md) глубина остаётся дополнительным режимом.
Убрана неподтверждённая сетка 0,5 м: глубины выбираются из допустимых интервалов с точностью
сохраняемого формата. Пользовательские минимум/максимум соблюдаются; максимум приложения
не объявляется нормативным пределом ТЗ. Обычная глубина 3 м, минимум 0,7 м и уклон не более
0,10 сохранены.

Профили решаются совместно на сети с одинаковыми глубинами в общих узлах. Техническое
разбиение одного физического прохода не стирает пересечение и не сокращает его полку 4 м.
Проверяются фактическая горизонтальная длина, физические границы полки, дорожные и трамвайные
минимумы, а также явные заданные глубины узлов. Округлённые длины отдельных рёбер не могут
создать превышение уклона; малая разность координат вычисляется до перевода в double.
Исключение в месте подключения ограничено настоящим корнем и его исходной тепловой сетью.

Стоимость интегрируется по горизонтальной длине. Средние глубины и разрезы при переходе
через 3 м не округляются преждевременно; перекрывающиеся специальные участки используют
максимальный коэффициент. Ценовой разрез сам по себе не создаёт новый геометрический узел.

Сохранённый экспорт независимо восстанавливает и проверяет профиль всей сети, его исходные
пересечения, интервалы, непрерывность и арифметику. Режим глубины и диапазон берутся из
сохранённых параметров запуска. Удаление всех профилей из результата с включённой глубиной
теперь отклоняется. Полная проверка всех экспортируемых вариантов заканчивается до записи
первого байта, включая повторную проверку перед непосредственной записью.

## Проверки до интеграции

Воспроизведения RED→GREEN сохранены в `.tooling/expert95/depth-prototype-evidence.md` и
`.tooling/expert96/`: законные глубины вне шага 0,5 м, полка через техническое разбиение,
наклон по фактической длине, перенос к большим координатам, неверное пересечение с тем же ID,
пропущенная часть полки и независимая стоимость. Exhaustive oracle интервального замыкания:
131625 конечных случаев цепей и графов. Application export-context: 7/7 PASS.

Общая финальная копия `.tooling/expert96/final1` (исправления глубины и отдельно проверенное
ускорение пересечений): 2049 случаев, 2046 PASS, 0 failures/errors, 3 opt-in scale skip,
179 классов, сумма времени 37,634 с. Исключены только три долгих dataset/control-класса;
они не объявляются пройденными. Все исходники сопоставлены с протестированной integration5;
отличия — только отдельный предикат ускорения и усиление official full test доверенными
параметрами экспорта. Исторические неудачи fixtures и компиляции сохранены отдельно.

Свежие полные расчёты и production для source96 пока не приняты. Результаты source95
не переносятся на новую версию автоматически. Серверный roads95 завершился без допустимых
вариантов; локальный roads95 PASS этого не отменяет. Причина расхождения исследуется.

## Ограничения

Продолжение четырёхметровой полки через настоящее ветвление или изменение ДУ остаётся
ограничением полноты поиска: такой нерешённый случай отклоняется, а не пропускается в экспорт.
Горизонтальный обход при невозможном профиле остаётся эвристикой. Исправление не является
доказательством глобально оптимальной трассы или закрытием R8, R/G, scale и всей задачи.
Вопрос о фиксированных дорожных 3 м и требуемом внешнем отступе для больших ДУ остаётся
открытым; это изменение не вводит ответ на него.
